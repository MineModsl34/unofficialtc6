# Porting plan: Thaumcraft 6.1.BETA26 (1.12.2) → NeoForge 1.21.1

Decisions and deviations are in [PORTING.md](PORTING.md).

**Status:** the code of all twelve stages is ported. The main survival path (first steps, alchemy, infusion,
basic foci, research) has been played through on a dedicated server, and the mod runs in a large modpack.
What remains is mostly manual acceptance: comparing world generation and the aura with the original, the full
research book on the client, long survival runs and multiplayer under load.

## 1. Scope

896 classes, ~110k lines of decompiled code, 855 textures, 307 models, 219 blockstates, 111 sounds.

The hardest part is the **client side (~32k lines, 117 files with direct OpenGL)**: it is rewritten, not ported.

## 2. Principles

1. **Bottom up, in vertical slices.** Each stage ends with a build that runs and a result that can be checked in game.
2. **Faithfulness first, improvements later.** Formulas, numbers and balance as in TC6. Bugs of the original are
   documented; only those that do not affect gameplay are fixed.
3. **The `thaumcraft.*` package structure is kept**, so old and new code can be compared class by class.
4. **The server must not depend on the client.** Every stage is checked on a dedicated server.
5. **Minimal rendering during the stages.** Complex effects get placeholders first and are finished in stage 11.
6. **Data through datagen.** Recipes, models, blockstates, loot, tags and languages are generated by code.
7. **Every decision goes into PORTING.md**; unfinished pieces are marked `TODO(port)`.

## 3. System mapping 1.12.2 → 1.21.1

| 1.12.2 | 1.21.1 | Where in TC6 |
|---|---|---|
| `GameRegistry` / `RegistryEvent` | `RegisterEvent` / `DeferredRegister` | Registrar, Config* |
| Blocks with metadata | One block per variant (Flattening) | 158 BlocksTC fields |
| `TileEntity` + `ITickable` | `BlockEntity` + `BlockEntityType` + ticker | 42 tiles |
| Item NBT | Data Components | Jars, crystals, casters, foci, infusion enchantments |
| Forge capabilities (player knowledge, warp) | Data Attachments + sync packets | PlayerKnowledge, PlayerWarp |
| `IItemHandler` capability | `Capabilities.ItemHandler.BLOCK` | Device inventories |
| `SimpleNetworkWrapper` + `IMessage` | `CustomPacketPayload` + `StreamCodec` | 40 packets |
| `Container` + `GuiContainer` | `AbstractContainerMenu` + `MenuType` + `Screen` | 36 containers, 32 GUIs |
| Recipes in code | `RecipeType` + `RecipeSerializer` + datagen JSON | Arcane, crucible, infusion |
| Ore Dictionary | Item tags (`c:`) | Aspects, recipes |
| `IWorldGenerator` | Configured/placed features + biome modifiers | ThaumcraftWorldGenerator |
| Biomes in code | Datapack biomes + **TerraBlender** | Magical forest, eerie biome |
| Structures in code | Features/structures | Mounds |
| Aura in a separate thread | Chunk Data Attachment + server tick | world/aura |
| `Potion` | `MobEffect` | 7 effects |
| Baubles | **Curios API** | Baubles and vis charms |
| `ModelBase` | `EntityModel` + `LayerDefinition` | 36 renderers |
| TESR | `BlockEntityRenderer` | 22 renderers |
| Direct OpenGL / LWJGL 2 | `RenderType` + `VertexConsumer` + core shaders | 117 files |
| GLE (tubes and beams) | Own mesh generation | 9 effect files |
| FX particles | Own particle engine on native render types | 19 particle classes |
| OBJ models (own loader) | NeoForge OBJ loader | client/lib/obj |
| `.lang` | `.json` | 9 languages |
| Forge config | `ModConfigSpec` | ModConfig |
| Access transformer | AT on Mojang names | tc_at.cfg |

## 4. Stages

| Stage | Content | Status |
|---|---|---|
| 0. Infrastructure | Registrar, network, config, datagen, imported languages/textures/sounds | Done |

| 2. Base content | Resources, ores, trees, plants, decorative blocks | Done |

| 5. Crafting | Salis Mundus, arcane workbench, crucible, infusion, all ConfigRecipes | Done |

| 7. Equipment | Tools, armour, Curios baubles, casters and the focus system | Done |
| 8. Mobs | 43 entity types, AI, models, bosses, champions | Done |
| 9. Golems | Golem builder, parts, AI, 16 seals | Done |
| 10. Flux, taint, eldritch | Taint spread, flux goo, liquid death, flux rift, void siphon | Done |

Open items: manual comparison of world generation and the aura with TC6; full client acceptance of the research
book; long survival paths through equipment, golems and flux; multiplayer and load in a full modpack.

The Outer Lands dimension is not implemented in BETA26 itself (only the biome and a config id exist), so it is
not part of the port.

## 5. Order and dependencies

```
0 → 1 → 2 → 3 ──────────────┐
          ├→ 4 → 5 → 6 → 7 → 9
          └→ 8 ──→ 10        │
                   11 ←──────┘ (minimal along the way, complete at the end)
```

## 6. Checks for each stage

1. `gradlew build` and unit tests of pure logic.
2. **GameTest** for in-world mechanics.
3. `runClient`: a manual check of the stage's content.
4. `runServer`: the server starts without client classes.
5. **The original is the reference**: a running 1.12.2 with TC6 to compare numbers and behaviour.

## 7. Risks

| Risk | Approach |
|---|---|
| Rendering: 117 files of direct OpenGL | Rewrite by meaning, compare with 1.12.2 screenshots; placeholders until stage 11 |
| Flattening: 158 block fields, some with meta variants | A "block:meta → new block" table in stage 2 |
| Thaumonomicon and research table are large GUIs | Ported separately in stage 4, function first, looks second |
| Biomes in the normal world need TerraBlender | An extra dependency |
| Aura in a separate thread | Moved to the server tick; watch performance |
| 1.21 items without aspects | Derivation from recipes plus a table of additions |
